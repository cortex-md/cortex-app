Cortex 0.2 moves the desktop app to a new foundation and brings databases, tasks, local history and a self-updating app on macOS, Windows and Linux.

**Updating from 0.1:** this version can't install itself over 0.1. Download it from this page once; from then on Cortex keeps itself up to date. Your notes stay where they are. Reopen your vault folder and sign in again after the first launch.

### New

- Automatic updates — signed downloads in the background that install when you quit, on every platform. Pick the stable or beta channel in Settings.
- Databases — table views over your notes' properties, with filters and fast scrolling on large vaults.
- Tasks — a task inbox and reminders that fire even with the window closed.
- Local version history — restore earlier versions of a note, even without sync.
- Obsidian importer — bring an existing Obsidian vault into Cortex.
- Writing mode — a distraction-free layout with a quick actions toolbar.
- Live collaboration and shareable note links for synced vaults.
- New vault switcher, compact settings and a ribbon you can hide.
- Intel Macs and RPM-based Linux distributions (Fedora, openSUSE) are now supported.

### Fixed

- Sync recovers from expired cursors, respects server rate limits and upload size limits.
- Version history only shows real changes.
- Faster startup, file tree and search on large vaults.
- Slash, vault and mention menus share one compact style.
