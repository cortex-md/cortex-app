First beta of Cortex 0.2: the desktop app on a new foundation, with databases, tasks, local history and automatic updates on macOS, Windows and Linux.

**Installing the beta:** download it from this page. Builds are not signed with an Apple or Microsoft certificate yet. On macOS, open Cortex once, then allow it in System Settings → Privacy & Security → Open Anyway. On Windows, choose "More info" → "Run anyway" if SmartScreen asks. Later betas install themselves. Coming from 0.1, reopen your vault folder and sign in again; your notes are not touched.

### New

- Automatic updates — signed downloads in the background that install when you quit. Beta builds follow the beta channel.
- Databases — table views over your notes' properties, with filters and fast scrolling on large vaults.
- Tasks — a task inbox and reminders that fire even with the window closed.
- Local version history — restore earlier versions of a note, even without sync.
- Obsidian importer — bring an existing Obsidian vault into Cortex.
- Writing mode — a distraction-free layout with a quick actions toolbar.
- Live collaboration and shareable note links for synced vaults.
- Intel Macs and RPM-based Linux distributions (Fedora, openSUSE) are now supported.

### Fixed

- Sync recovers from expired cursors, respects server rate limits and upload size limits.
- Faster startup, file tree and search on large vaults.
