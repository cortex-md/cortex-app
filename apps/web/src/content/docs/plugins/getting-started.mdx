This guide creates a small plugin with one command that inserts text into the active editor.

## Scaffold

```bash
cortex create hello-cortex --plugin
cd hello-cortex
```

The CLI writes a project that loads in Cortex as-is, with CI and release workflows, then
initializes git and installs dependencies.

```text
hello-cortex/
  manifest.json
  package.json
  tsconfig.json
  src/index.ts
  .github/workflows/
```

## manifest.json

`manifest.json` is the single source of truth for the plugin identity:

```json
{
	"id": "hello-cortex",
	"name": "Hello Cortex",
	"version": "0.1.0",
	"minAppVersion": "0.1.0",
	"author": "Your Name",
	"description": "Adds a sample command.",
	"icon": "sparkles",
	"main": "dist/index.js",
	"permissions": ["editor:write"]
}
```

The loader reads only `id` and `main` from this file; everything else comes from the manifest the
bundle passes to `definePlugin`, and the two ids must match.

`main` must be a safe relative path inside the plugin directory. Absolute paths, drive-letter paths,
empty paths, and paths containing `..` are rejected. Versions are plain `MAJOR.MINOR.PATCH`;
pre-release suffixes break update checks.

## Package

```json
{
	"name": "hello-cortex",
	"private": true,
	"version": "0.1.0",
	"type": "module",
	"scripts": {
		"build": "bun build ./src/index.ts --outfile ./dist/index.js --target browser --format cjs --external @cortex.md/api --external @codemirror/state --external @codemirror/view",
		"typecheck": "tsc --noEmit"
	},
	"dependencies": {
		"@cortex.md/api": "^0.1.0"
	},
	"devDependencies": {
		"typescript": "~5.8.3"
	}
}
```

The bundle is CommonJS for the browser. Only `@cortex.md/api`, `@codemirror/state`, and
`@codemirror/view` may stay external; everything else must be bundled.

## Plugin Entry

```ts
import { definePlugin, type PluginManifest } from "@cortex.md/api"
import manifest from "../manifest.json"

export default definePlugin({
	manifest: manifest as PluginManifest,
	contributes: {
		commands: [
			{
				id: "insert-hello",
				label: "Insert Hello",
				icon: "sparkles",
				defaultHotkey: "mod+shift+h",
				run: (ctx) => ctx.editor.insertAtCursor("Hello from Cortex"),
			},
		],
	},
})
```

Importing `manifest.json` keeps the bundle's manifest id identical to the file the loader reads, so
ids never drift. The command appears in the palette, hotkey settings, and Vim command line as soon
as the plugin is enabled; `run` executes only when invoked.

## Run It in a Vault

```bash
cortex dev --vault ~/Notes
```

`cortex dev` builds the plugin and copies it into `<vault>/.cortex/plugins/hello-cortex`, then
rebuilds on every change. Cortex reloads the plugin automatically. Enable it once in
Settings > Plugins. Prefer `cortex dev` over symlinking the project folder: the hot-reload watcher
does not follow symlinks.

- `--once` installs and exits.
- `--clean` removes the development copy.

## Check Before Releasing

```bash
cortex check
```

`cortex check` builds the plugin, loads the bundle exactly like Cortex does, and runs the checks the
Marketplace registry applies.
